## Data

All original data used in this study are publicly available and can be obtained from the corresponding data providers described in the **Data Sources** section of the manuscript.

The analysis integrates data from:

- Sentinel-1 Synthetic Aperture Radar (SAR)
- Sentinel-2 optical imagery
- ERA5-Land reanalysis data
- publicly available spring wheat distribution and phenological information

The processed input file used by the analysis workflow is:

`spring_wheat_with_phenology_phases.csv`

The processed dataset is not included in this repository. The original datasets are publicly accessible, and their sources and access information are provided in the **Data Sources** section of the manuscript.

After preprocessing and data integration, the input table contains the variables required for the cross-domain analysis, including region, year, sample identifier, acquisition date, orbit information, NDVI, SAR variables, thermal-time variables, and environmental variables.

For detailed information on data sources, spatial and temporal coverage, and preprocessing procedures, please refer to the associated manuscript.
