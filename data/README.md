# Data

All data used in this study are derived from publicly available data sources. The original datasets can be obtained from the corresponding data providers following the information provided in the **Data Sources** section of the associated manuscript.

The analysis integrates data from:

* Sentinel-1 Synthetic Aperture Radar (SAR)
* Sentinel-2 optical imagery
* ERA5-Land reanalysis data
* publicly available spring wheat distribution and phenological information

The processed input file used by the analysis workflow is:

`spring_wheat_with_phenology_phases.csv`

This file is generated after preprocessing and data integration and is not included in this repository. Users can obtain the original datasets from the public sources described in the manuscript and reproduce the required input data following the same data-processing procedure.

The input dataset used by the modeling scripts contains region, year, sample identifier, acquisition date, orbit information, NDVI, SAR variables, thermal-time variables, and environmental variables.

For detailed descriptions of the datasets, spatial and temporal coverage, preprocessing procedures, and access information, please refer to the **Data Sources** section of the manuscript.
